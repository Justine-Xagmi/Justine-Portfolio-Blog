About

I'm an IT Specialist with a strong pull toward artificial intelligence and a habit of turning ideas into working software rather than leaving them as notebooks. Most of what I build sits at the intersection of the two: a model or an analysis on one side, and a real interface — web or mobile — that makes it usable on the other.

I got into this through curiosity about how machines learn patterns from data, and it grew into a broader interest in the full pipeline: cleaning and exploring data, training and evaluating models, and then shipping them inside applications people can actually open and use. I'm equally comfortable writing a data pipeline in Python and building the API and interface around it.

Where I'm headed: deeper into applied AI and machine learning engineering, with software development as the skill that lets me deliver that work end-to-end instead of handing it off halfway. I'm currently completing my B.Sc.IT & Data Science, expected in 2027, alongside hands-on project work and a recent AI/ML/IoT bootcamp.
